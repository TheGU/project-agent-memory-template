remote.** At the flip to GitHub mode (`docs/wiki/going-production.md`) every open note becomes a
GitHub issue via `gh issue create` - after first re-verifying its claim against the code - and
this file is deleted. Keep notes issue-shaped so that conversion is mechanical, not a project.

Claim a note by declaring it in a `sessions/active/` file's scope, not by editing here. Remove
done notes - history lives in `sessions/archive/` + git. A deferred note carries one line
`defer-until: <phase or condition>`.
